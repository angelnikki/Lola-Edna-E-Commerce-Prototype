# Lola Edna’s Homemade Food – E-Commerce Prototype

*Note: This is an old second-year academic project from our CSP 115 - Human Computer Interaction class, originally submitted in April 2026. I've uploaded this repository for archiving purposes.*

## About the Project

Lola Edna’s Homemade Food is a prototype e-commerce web application for a local business specializing in authentic delicacies and home-cooked meals. It was built to solve their manual order tracking issues by providing a centralized digital storefront.

## Features

* **User Authentication:** Basic secure login system.
* **Product Catalog:** Food menu display complete with images, descriptions, and pricing.
* **Order Management:** Cart functionality and basic order status tracking (e.g., Pending, Preparing, Out for Delivery).
* **HCI Principles:** Designed with clear visual feedback for interactive elements to ensure an intuitive checkout flow for users.

## Limitations

* Payment processing is limited to Cash on Delivery (COD).
* Real-time GPS tracking for delivery riders is not supported.
* This prototype was designed to be run locally for academic demonstration purposes and is not deployed to a live public server.
